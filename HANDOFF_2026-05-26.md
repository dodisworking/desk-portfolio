## How to run

```bash
cd /Users/jarvis/Pixar/desk-portfolio
npm run dev
```

Then open **`http://localhost:3001`**. Hard-refresh once (Cmd+Shift+R) if you suspect cache. DevTools → Network → "Disable cache" is your friend.

### Cache buster

`index.html` head has an `APP_VERSION` constant. On mismatch with localStorage it unregisters service workers, clears Cache API, and reloads with `?_v=<ts>`. Current version:

```
APP_VERSION = '2026-05-26-hide-warp-panel-r107';
```

**Bump it on every meaningful UI change.** Format: `YYYY-MM-DD-<short-tag>-r<n>`.

### If edits don't appear

Diagnose in this order — do NOT write more code until each is ruled out:

1. **Wrong URL** — confirm `localhost:3001`, NOT 3000.
2. **Stale Vite cache** — `rm -rf node_modules/.vite` + restart `npm run dev`.
3. **Browser cache** — DevTools open with "Disable cache" checked.
4. **Cached `dist/`** — only matters if they hit port 3000 by mistake; hard-reload after switching.

### Closure gotcha (read this twice)

```
enterPortfolio()          ← creates legoBubble, __tedxTvGroup, __watchMesh, panels…
setupSpaceScene()         ← SIBLING (not nested!) — contains tick() loop
```

`setupSpaceScene` can NOT see local consts from `enterPortfolio`. **Every cross-scope value lives on `window.__*`.** Examples already in use:

- `window.__legoBubbleEl`, `window.__legoBubblePath`, `window.__legoBubbleSvg`
- `window.__legoBubbleMode`, `window.__legoBubbleIntensity`, `window.__legoBubbleModes`
- `window.__tedxTvGroup`, `window.__tedxTvOpacity`, `window.__tedxTvZoomed`
- `window.__tedxWatchMesh`, `window.__tedxWatchMat`, `window.__tedxWatchPos`, `window.__tedxWatchTweakPanel`
- `window.__diceNudge`, `window.__vhsEditFocusId`, `window.__vhsBobAmount`
- `window.__legoPickStart`, `window.__legoBubbleStageIdx`, `window.__legoBubbleLastCtxKey`

If a tick-loop reference throws `ReferenceError`, you put it in `enterPortfolio`'s local scope. Move it to `window.__*`.

## What's currently in place

### Side monitor (right of TV)
- `simple_monitor.glb` parented to TV's `grp`. Fades in on first VHS click.
- Canvas display plane with custom shader: `uMap, uOpacity, uCrop{T,B,L,R}, uCornerR, uFlipX, uFlipY`.
- Auto-flips UV.x when `scaleX < 0` (mirrored monitor).
- Locked transform — sliders for monitor pose are dialed-in. The Side Monitor + VHS Look HTML panels are `display: none`.

### VHS library + brand schemes
- 13 tapes with hand-written `clientName` / `blurb` / `spotNames` / `videoSrcList` / `runtime`.
- Random shuffle on TV entry (biased — never starts on `retro_coke_doc` or `era_coalition`).
- `__BRAND_SCHEMES[spec.id]` auto-applies per-client background + accent on every VHS click (Samsung, Verizon, Premier Protein × Ogilvy, Coke, Ad Council, Citizens, ERA, IKEA, Dove, Schwinn, H&R Block, DreamWorks Shrek).
- Canvas display layout: `CLIENT` → big name → `NOW PLAYING` → spot title → `COMING UP NEXT` → ALL spots (active highlighted). "Learn more" drawn unconditionally; blurb fallback if missing.
- Auto-fit helpers: `_fitFont` (binary search single line) + `_fitWrap` (wraps within budget).
- Black backings behind non-Shrek VHS tags re-asserted via 200 ms interval (the applier kept tinting them).

### Pixar / AI blurb toggle
Per-spot Pixar-mode (cinematic) vs AI-mode (technical) blurbs. Toggle in the side monitor.

### Dice
- Slot-machine random tape spinner above the carousel on TV entry.
- `/Users/jarvis/Downloads/dice.glb` source; lives in items.
- Auto-plays chosen tape **muted-then-unmute** to bypass autoplay block.
- Tweak panel: Shift+D toggles `__dicePanel`. X/Y/Z/Scale + idle-float Bob slider. Bob freezes to 0 when hovered.
- Spawn lock prevents click-grabbing while flying.

### Items 2.0
- Top-left purple "📦 Items 2.0" button (in `main.jsx`).
- Pulls list from `/items-bank-2/index.json`. `dropItem(file, label, bankPath, opts)` accepts `bankPath` ('items-bank' or 'items-bank-2') and `opts.autoSelect/locked`.
- These go in the MAIN ROOM list, not the lego list: yeti, rodney, rusty, omnitrix, et_poster.

### Lego scene (the centerpiece)
- 6 lego children: `tablet`, `diploma`, `costa_rica`, `ogilvy`, `pixar_ball`, `tedx` — laid out in a fixed-column row.
- When one is picked, it elevates to the LEFT of lego at `LEGO_X - 0.95` with `scaleMult: 1.36`; the other 3 (or 5) shrink to `scaleMult: 0.92` and recenter under lego.
- Lego itself has a very tiny bob (`bobAmtY = 0.015, bobAmtX = 0.005`) so the speech bubble doesn't drift over neighbors.

### Lego speech bubble
- Hand-drawn SVG path with `feTurbulence` + `feDisplacementMap` filter.
- White stroke, draw-in `stroke-dasharray` animation.
- Typewriter that expands bubble width as text is typed.
- **Anchored to `legoMi.spec.basePos`** (the STATIC layout pos), NOT live `group.position`. Anchoring to live caused drift.
- Y offset: `+1.2` for face height.
- Content adapts to `pickedId` via context map (`lego`, `diplomaFirst`, `diplomaLater`, `tedx`, etc.).
- Diploma has first-time vs later-time intro variants. Trilingual flex (Costa Rican 🇨🇷 native, Portuguese, Spanish, English).
- Warp modes available in code: `Still / Pencil / Inky / Sketch / Electric / Glitch`, intensity 0–2.5.
- **The warp type panel UI is hidden (`display: none`)** — the mode + intensity are dialed in. `window.__legoBubbleMode` and `window.__legoBubbleIntensity` still drive behavior; if you need to change them, set them from console or re-show the panel.

### TEDx CRT TV
- `public/models/crt_tv.glb` loaded into `__tedxTvGroup`.
- Sits to the right of lego. Emerges from deep `-Z` (basePos.z − 6.0) → settled `basePos.x + 1.5, basePos.y + 0.55, basePos.z − 0.2`.
- `rotation.y = Math.PI` (faces camera dead-on).
- Scale 0.88 → 1.0, opacity 0 → 1, lerp 0.025 (slow + cinematic).
- Auto-shows whenever `pickedId === 'tedx'`.
- Click TV (or the "📺 watch it" button in the bubble) → `__tedxTvZoomed = true` → camera dollies in (focus = TV pos, zoom × 0.35).
- The old HTML "click to watch" overlay (`__tedxWatchPanel`) is **`display: none`** — replaced by a 3D mesh.

### TEDx 3D watch screen (newest)
- `_watchMesh` is a `PlaneGeometry(1.0, 0.75)` (4:3) plane parented to `_tedxTv`.
- Material: `MeshBasicMaterial` with a `CanvasTexture` drawing the play circle, "CLICK TO WATCH", "TEDxEMORY · 2019" caption.
- Transparent, `depthWrite: false`, `side: DoubleSide`, `toneMapped: false`.
- `rotation.y = Math.PI` (matches TV's flipped orientation).
- Initial transform from `localStorage['desk-portfolio:positions:v1']` keys `tedx.watch.{x,y,z,scale}` (defaults `0, 0.05, 0.32, 0.6`).
- Opacity follows `__tedxTvOpacity` (fades in once TV is >35% emerged, lerp 0.12).
- **📺 TEDx Watch Screen tweak panel** (top-right, pink border) — X / Y / Z / Scale sliders. Only visible when `pickedId === 'tedx'`. Live-updates the mesh and persists each slider.
- Click hit-test: the existing TV raycast already hits this mesh because it's a child of `_tedxTv`.

### Edit Mode button
- Top-center "⚡ MAKE IT SMOOTH" button (`main.jsx`) — drops perf to turbo + DPR 0.4 so the main room is editable smoothly.
- **No localStorage auto-restore on boot** (caused black render). User must click each session.

### Session error log
- Floating red "📋 Errors" button bottom-right (`main.jsx` IIFE at very top).
- Captures `window.onerror`, `unhandledrejection`, `console.error`. Copy / Clear buttons.

## Tips & traps for the next context window

1. **`grep` before you edit.** If the user says "you didn't do X" and `grep -n 'X' src/portfolioOverlay.js` shows the code is there, the problem is browser cache or port 3000. Tell them to hard-refresh on `localhost:3001`.
2. **`window.__*` is the contract** between `enterPortfolio` and `setupSpaceScene`. Don't try to share a `const` across them.
3. **Read the per-frame block** before adding effects. It's at line ~11270+ for the lego bubble logic, ~10780+ for TEDx TV emergence, ~11516+ for the watch screen opacity. Most "weird drift" or "doesn't appear" bugs are state being clobbered there.
4. **Anchor to `spec.basePos`, not `group.position`**, when you want something to NOT bob with the lego.
5. **Bump `APP_VERSION` on every UI-visible change.** Forgetting causes "you didn't fix it" complaints.
6. **Don't auto-restore Edit Mode on boot.** The user has to click the button — historical regression.
7. **Don't run `git add .` or `git commit` unless explicitly asked.** Hard saves only on request.
8. **Don't touch `dist/`.** Dev doesn't use it.
9. **Migration wipes are forbidden.** No code should ever blow away localStorage keys.
10. **Verizon / Pete Davidson** videos are hosted locally — iSpot.tv was the working source after YouTube SABR/PO token broke yt-dlp. Don't try to re-download from YouTube.
11. **When adding a slider panel**, copy the dice panel pattern (line ~928+) — local helper `_mkRow(label, key, opts)` with min/max/step/def/persist. Mutates a `window.__*` object and writes to `localStorage['desk-portfolio:positions:v1']`.
12. **The boot overlay is for WebGL loading.** In production (Hyperbeam stream gate), it gets removed by `pixelStreamGate()` and replaced by the streaming gate. Don't break either flow.
13. **The user types fast and makes typos.** Read intent. "th eteh screen ahs to be 3d" = "the screen has to be 3D." Don't ask for clarification on typos.
14. **Quality > speed.** This is a portfolio piece for landing a job at Pixar. When in doubt, take the higher-craft path.
