### If edits AREN'T showing up

This was a recurring problem all session. Diagnosis order:

1. **Wrong URL.** Confirm the user is on `http://localhost:3001` (Vite dev server), **NOT** `http://localhost:3000` (which is the production Express server in `server/index.js` that serves `dist/`). The wrong port silently serves an old static bundle.
2. **Stale Vite cache.** `rm -rf node_modules/.vite` and restart `npm run dev`.
3. **Browser cache.** Open DevTools → Network tab → check "Disable cache." Leave DevTools open while testing.
4. **Cached `dist/`.** If the user was on port 3000 by mistake at some point, they may have a browser-cached old `dist/` bundle. Hard-reload (Cmd+Shift+R) once after switching to port 3001.

If after all four they still see old behavior, **don't write code** — run `grep` in the file for the change in question and prove to the user it IS there. Most "you didn't do it" complaints in this session were the URL/cache, not missing code.

## What's actually in `src/portfolioOverlay.js` (verified by grep)

### Side monitor (right of the TV)
- `simple_monitor.glb` parented to the TV's `grp`
- Fades in on first VHS click (`_hasAppeared` latch, 1 s opacity)
- Locked resting `rotY = 2.112`; swing animation disabled
- Canvas display plane overlays the yellow screen area
  - Defaults: `screenX = -0.053, screenY = 0.542, screenZ = 0.555, screenScale = 0.686`
  - Numbers derived from offline analysis of the GLB's yellow-rect vertex bbox
- Custom shader: `uMap, uOpacity, uCropTop/Bot/Left/Right, uCornerR, uFlipX, uFlipY`
- Auto-flips UV.x when `scaleX < 0` so the canvas content reads correctly through the mirrored monitor

### Migration wipes — DISABLED
All `placed_v4 / v5 / v6` migrations that nuked `localStorage` keys are commented out. Previously they caused "back 20 steps" frustrations. Dialed-in positions persist across reloads.

### Cache busting (still useful for browser refresh)
`index.html` head has:
- `<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate" />`
- Inline script comparing `APP_VERSION` (currently `2026-05-21-panel-force-r7`) to localStorage; on mismatch it unregisters service workers, deletes `caches`, reloads with `?_v=<ts>`.

Bump `APP_VERSION` to force a fresh fetch.
